# Inven - Garmin Connection

Proyecto para conectar y sincronizar datos desde dispositivos Garmin.

## Funcionalidades

- Conexión a Garmin Connect API
- Sincronización de actividades
- Importación de datos de entrenamientos
- Análisis de datos fitness

## Configuración

### Requisitos
- Node.js 16+
- Credenciales de Garmin Connect

### Instalación

```bash
npm install
```

### Variables de Entorno

```
GARMIN_USERNAME=tu_usuario
GARMIN_PASSWORD=tu_contraseña
```

## MCP Integration

Este proyecto integra con el MCP (Model Context Protocol) de Garmin para acceso a datos.
